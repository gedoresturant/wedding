# نظام مجموعة النسيم — الإصدار الجديد v2

واجهة عربية RTL جديدة مبنية على Supabase Auth + PostgreSQL، ومهيأة للنشر عبر GitHub Pages. ملفات الإصدار القديم لا يتم تعديلها.

## حالة التنفيذ
هذه نسخة تأسيسية قابلة للتطوير، وليست إعلانًا عن اكتمال كل وظائف ERP. تشمل شاشة الدخول، لوحة أساسية، إدارة القاعات والعملاء، إنشاء الحجز مع منع تعارض الفترة، وتسجيل التحصيل عبر RPC مع فحص المبلغ المتبقي. يجب استكمال إدارة المستخدمين، الباقات والإضافات، QR آمن مع تحقق server-side، تقارير متقدمة، واختبارات E2E قبل استخدامها تشغيليًا.

## إعداد Supabase
1. طبّق ملف `supabase/schema.sql` في SQL Editor بعد مراجعة المشروع المستهدف.
2. أنشئ مستخدمًا من Authentication.
3. أنشئ سجل شركة في `wf2_companies` ثم اربط أول مستخدم بجدول `wf2_profiles` بدور `admin` من SQL Editor. لا تفتح صلاحية التسجيل العام للإدارة.
4. ضع Project URL وpublishable/anon key فقط داخل `app.js`. لا تضع service_role key في الواجهة.
5. أنشئ GitHub Actions workflow للنشر إلى GitHub Pages مع إعداد Pages من Actions.

## تنبيه
قاعدة البيانات الحالية تحتوي جداول وبيانات للإصدار السابق. ملف SQL هذا يضيف جداول منفصلة تبدأ بـ `wf2_` ولا يحذف أو يغيّر جداول الإصدار السابق. لا تستخدم بيانات حقيقية قبل استكمال مراجعة الأمان والاختبارات.
